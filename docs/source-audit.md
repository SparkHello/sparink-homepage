# Sparink 当前实现整理记录

日期：2026-11-15。对照上游基线 `06d490a` 与整理前版本 `fdc46df`。

## 核对方法

从 Next.js 的页面、布局、接口入口和本地 Studio 脚本建立引用关系，结合 Git blob、差异与提交来源检查仍在使用的实现。未使用的文件需要同时确认当前入口不可达、数据不依赖它，才从发布树移除。未改写历史提交，也未删除历史导入的个人照片。

文件相同或不同都只是辅助证据；这份记录说明工程替换范围，不将字符串差异当作版权独立性的法律证明。

## 独立重写

- 音乐播放器：只保留 `useMusic` 的调用合同与现有纸袋光盘界面。新 `lib/music/player.ts` 以一个浏览器音频元素和独立的选择会话管理播放；`model.ts` 处理曲目、缓存与歌词；`client.ts` 负责请求与取消；Provider 负责 React 适配和进入歌单页后的按需加载。实现者以现有 UI 合同、歌曲配置及浏览器媒体标准为依据，未按旧播放实现翻写。
- 音乐接口：按现有 `ids` / `lyricId` 请求与歌曲 / LRC 响应合同重新实现。新处理器独立校验上游数据，提供超时、有限缓存与并发合并，不再回访线上旧接口作为本地兜底。
- 退役接口：`/api/chat`、`/api/github`、`/api/weather` 只留下新写的明确 404 响应，保持原有关闭状态与响应内容，旧服务逻辑全部移除。
- 站点配置：只保留当前身份、社交入口、内容开关和歌单 ID；旧背景、示例封面、AI 猫、弹幕、等级及评论配置全部移除。

## 清理

- 删除旧 `my-blog-manager/`：133 个跟踪文件均与上游相同，当前 Studio 不依赖它；删除前确认无未跟踪或忽略的本地配置与数据。
- 删除旧 `picture/`：46 个上游说明截图，同样确认无额外本地文件。
- 删除不可达的旧导航、评论、播放器外观、天气、背景、时间线、工具箱、实验页面辅助组件，以及无消费者的主题 Provider。
- 删除旧猫图片、飞船模型、旧配置补全脚本和更新日志；同时移除已不用的旧关于页内容与 Reveal 组件。
- 移除 9 个无用直接依赖：React Three Fiber / Drei、Framer Motion、next-themes、OpenAI SDK、remark、remark-html、highlight.js 和 Tailwind Typography。代码高亮仍通过 rehype-highlight 的依赖使用 highlight.js；Three.js 类型从间接依赖改为显式开发依赖。
- 保留 Next.js 工具说明、CLAUDE 转引和标准 Tailwind/PostCSS 配置。标准脚手架语句未为制造差异而重写。

## 保持不变

米白与钴蓝的界面、丝线雕塑、照片透镜、可拨动相片堆、月份滚轮、日记搜索、文字旁注、阅读刻度和光盘外观继续保留。相册过渡另修复一处边界身份问题：预览照片变化时同步更换 ViewTransition 的 key，避免快速打开详情时残留旧照片名称。

两本相册共 62 张照片，全部上传文件（含历史导入）、头像、歌单、内容开关和 Markdown 目录未改动。Studio 继续直接维护这些数据；日记仍允许无标题与无封面。现有页面和相册链接继续有效。

`XHBlogs` 目录名暂作部署路径兼容：Cloudflare 构建根目录与 Studio 的内容发布路径保持原样，目录名不构成运行时模板依赖。
